总览架构图

从工作区编排层开始，串到采集、加工、训练，再到推理和在线部署。

一句话概括：本项目是把 real/sim 采集来的 Go2 导航数据，统一加工成“图像 + 指令 + 状态 -> 未来 K 步速度块”的训练样本，再用 LLaDA-V backbone + 自定义动作头学习该映射，并放入在线控制环执行。

数据流细化图

回答“数据从哪里来，怎么变成训练样本，以及训练 loader 最终拿到什么”。

最重要的拐点有四个：raw session -> Sample、Sample -> processed record、processed jsonl -> prompt + labels、collate -> Trainer batch。

模型前向 / 推理细化图

回答“样本进模型后，训练时如何做 masked denoising，推理时如何做 iterative remasking”。

训练时是“真实动作嵌入 + 随机遮挡 + 恢复被遮动作”；推理时是“全 mask 初始化 + 多轮逐步解析 + 解码成连续速度 + 安全过滤后执行”。
